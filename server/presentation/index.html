Agentic Loop

Namespace → Machine → Sidecar topology. Sidecars self-register and heartbeat every 30s. Dead nodes flagged automatically.

Phase 3 — Shipped

Built for Engineering & Operations

📊
Charts on demand
Claude derives data from log lines and renders bar, line, or pie charts. No manual data wrangling.
⚠️
Anomaly detection
If logs contain SIGTERM, crashed, or shutdown — Claude flags it at the top, even when not asked.
💬
Rich answers
Full markdown rendering — tables, code blocks, bold text. Structured summaries, not raw grep output.
🗂
Source attribution
Every answer shows which files matched on which machine, with line counts. Click to expand.
🔍
Arbitrary paths
"Search /var/log/custom.log on server1" — agent routes directly. No pre-registration needed.
👍
Feedback loop
Thumbs up/down on every answer. Persisted in DB to monitor and improve answer quality over time.
More Capabilities

Designed for power users

💡 Multi-turn conversations
Full history sent to Claude on every follow-up. "What time did the error happen?" — Claude remembers context across the session.
🎯 Process chooser
Ambiguous query? Claude presents clickable option buttons instead of a free-text box. No typing required.
⬇️ Export to Markdown
Download any answer or full conversation as a .md file — ready for post-mortems and incident reports.
📡 Fleet health at a glance
Admin UI shows every namespace, machine, and sidecar. Status updated every 30s — alive / dead.
💰 Token & cost visibility
Every answer shows N tokens · ~$X.XXX. Usage persisted per message. Full audit trail.
🔒 Read-only & secure
Rust sidecar has zero write surface. Systemd hardening. Secrets never in config. Auth tokens + TLS in Phase 4.
